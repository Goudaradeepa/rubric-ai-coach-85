# Insightful Grader

Build an AI-powered student answer evaluation system using rubrics.

Features:

- Teacher uploads question, model answer, and rubric criteria.

- Students submit answers through a web interface.

- AI compares student answers with the model answer using semantic similarity.

- Evaluate based on rubric criteria like concept understanding, explanation quality, and completeness.

- Detect misconceptions in student answers.

- Generate feedback and improvement suggestions.

- Show final score and detailed evaluation.

Pages required:

1. Teacher Dashboard

2. Student Answer Submission Page

3. AI Evaluation Results Page

4. Performance Analytics Dashboard

Use a clean dashboard UI with charts showing student performance.
